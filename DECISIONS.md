How to use this file

- One table of decisions. Every row has an ID (DEC-nn) and an Owner (the member whose chat produced it; "Team" = from the project handoff).
- Status: **settled** (agreed or verified), **proposed** (someone suggested it, not confirmed by the group), **unverified** (not checked against official docs or a real run).
- Where two sources disagree, both sides stay visible in "Conflicts". The group picks the winner, then the row is updated here.
- Never put secrets (keys, passwords, tokens, database credentials) in this file or in any chat.
- If a chat's advice conflicts with this file, flag it. If a project document and this file disagree, the newer decision wins and the document gets updated.
